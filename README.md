# To-Do Web Application

A simple and interactive To-Do List web application built using **HTML, CSS, and JavaScript**.  
This project is created as part of the **SkillCraft Technology Internship Task**.

---

## Objective

The goal of this project is to create a task management system where users can add, edit, delete, and organize their daily tasks with date and time.

---

## Features

- Add new tasks
- Set task date and time
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Simple and clean user interface

---

## Technologies Used

- HTML – Structure of the app
- CSS – Styling and layout
- JavaScript – Functionality and DOM manipulation
